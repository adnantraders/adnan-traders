App lock

Lock is off

The lock keeps other people out of the app on this phone. If you forget the password, the only way back in erases the data on this phone, so keep a backup file. Backup files themselves are not locked, keep them private.

Your data lives on this phone

Everything is saved on this device and works without internet. Save a backup file often and keep a copy outside the phone, so you can bring everything back if the phone or the app is lost.

Cloud backup (Google account)

Not set up

Sign in with your Gmail and your data is backed up automatically, like WhatsApp. If the phone is lost, install the app on a new phone, sign in with the same Gmail and press Restore from cloud. Each Gmail has its own separate data.

Save a backup

Tip: use Send backup file to put a copy in WhatsApp (message yourself) or Google Drive.

Restore a backup

Cannot choose the file? Paste the backup text instead

Restoring adds the records from the backup. It does not delete what is already on the phone. Backups from the older Claude version of this app also work.
